# Intent — older than the code

**Nothing in this folder is a description of what Lyra does.** These are the documents that came
before it: the shape someone wanted, written at a time when the thing did not exist yet.

They are kept because *why* is genuinely hard to reconstruct later, and these say it well. They are
in their own folder because the alternative — leaving them beside the documents that describe the
running system — is how a reader ends up believing a feature exists because a 561-line vision
document described it in detail.

> **Never cite anything here for what is.** For that, start at
> [the index](../README.md), or at [`CLAUDE.md`](../../CLAUDE.md) in the repo root.

| Document | What it is | Written |
|---|---|---|
| [Vision](./vision.md) | The original product: a family life OS with proactive AI. Much of it is built, some of it was dropped, and the document does not distinguish them | before the Rust port |
| [Soul](./soul.md) | The assistant's intended personality — three archetypes, one voice | before any assistant existed |
| [Minimalist Mind](./minimalist-mind-life-os.md) | A design specification for "Life OS (Keel)", an earlier name | earlier still |
| [Strategic Blueprint](./strategic-blueprint.md) | The strategic identity conversation these grew out of | March 2026 |

If something in here is still true and still matters, the right move is to write it into the
document that describes the running system and delete it from the one that does not. That is how
the three dead docs went in September 2026, and why this folder is now four files rather than
seven.
